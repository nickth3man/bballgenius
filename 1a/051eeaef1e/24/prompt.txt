Final-answer contract:

- produce exactly one final answer,
- store it in a clear state field such as `final_answer`,
- set a clear flag such as `is_final: true`,
- set a clear `stop_reason`,
- route directly to LangGraph `END` after a final answer,
- never call tools after a final answer exists,
- never append repeated final answers,
- never include follow-up offers in test mode,
- answer only the question asked,
- keep final answers concise and directly comparable to expected answers.

A valid answer followed by repeated copies is still a failure.
