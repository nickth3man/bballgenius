## Task: Unicode Box-Drawing Table Formatter

Create `formatResultsTable(results: Record<string, unknown>[]): string` that formats SQL query results as Unicode box-drawing tables, matching the hub's `formatTable` style.

### Reference Pattern (hub's formatTable output)

```
┌──────────────┬────────┐
│ player       | points │
├──────────────┼────────┤
│ LeBron James │     30 │
│ S. Curry     │     28 │
└──────────────┴────────┘
```

Key characters: `┌ ┬ ┐ ├ ┼ ┤ └ ┴ ┘ ─ │`

### Function Signature

```typescript
export function formatResultsTable(results: Record<string, unknown>[]): string
```

### Behavior

1. Extract headers from `Object.keys(results[0])`
2. Convert all values to strings (null/undefined → empty string)
3. Calculate column widths from max(header.length, max_value_length)
4. Auto-detect numeric columns → right-align (check if value is `!isNaN(Number(val))`)
5. Build box-drawing table lines
6. If results > 20 rows, show only first 20 and prepend `Rows: N (showing first 20)\n`
7. Empty array → return `'Query returned no results.'`
8. Join all lines with `\n` and return single string

### Example Output

For input `[{ player: 'LeBron James', points: 30 }, { player: 'Stephen Curry', points: 28 }]`:

```
┌───────────────┬────────┐
│ player        │ points │
├───────────────┼────────┤
│ LeBron James  │     30 │
│ Stephen Curry │     28 │
└───────────────┴────────┘
```

Note: Each cell has 1 space padding on each side (` ${padded} │`).
