Find real-world example projects that use `@opentui/core` on GitHub. The goal is to discover visually polished terminal UIs built with OpenTUI that could serve as design references for a chat application.

**Search strategy — use ALL of these in parallel:**

1. **gh_grep**: Search for code patterns that indicate OpenTUI usage:
   - `from '@opentui/core'` (TypeScript imports)
   - `require('@opentui/core')` (CommonJS imports)
   - `BoxRenderable` (core component)
   - `TextRenderable` (core component)
   - `ScrollBoxRenderable` (core component)
   - `InputRenderable` (core component)
   - `CliRenderer` (core renderer)
   - `StyledText` (text styling)
   - `createTestRenderer` (testing utility)
   - Filter by language: TypeScript, TSX, JavaScript

2. **firecrawl search**: Search for:
   - "opentui" site:github.com
   - "@opentui/core" terminal UI
   - "opentui" npm package examples
   - Also check the npm page for @opentui/core to find dependents/repo link

3. **firecrawl scrape**: If you find the OpenTUI GitHub repo or org page, scrape it for:
   - README examples section
   - Showcase or gallery
   - List of dependent repos
   - Any linked example projects

**What to return for each project found:**
- Repository URL (owner/repo)
- What it does (brief description)
- Which OpenTUI components it uses
- Visual quality indicators: does it use borders, colors, markdown rendering, animations, multi-panel layouts, message bubbles?
- Any particularly polished UI patterns worth copying for a chat TUI
- Stars count if visible

**Also check:**
- The `@opentui/core` npm package page for links to the source repo
- Any OpenTUI org on GitHub
- The BBallGenius repo itself already uses OpenTUI — note what the hub does visually that the chatbot doesn't (hub uses rounded borders, box-drawing tables, TabSelectRenderable, multi-panel layouts)

Be thorough — search at least 5 different gh_grep patterns and 3 firecrawl queries.
